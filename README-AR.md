# Stage 7 — الطباعة الأصلية داخل Android

تم الحفاظ على Stage 6 الخاص بالأعمدة الثمانية.

## ما الجديد؟
- زر الطباعة يعمل من داخل تطبيق Android عبر جسر طباعة أصلي باستخدام Android PrintManager.
- يدعم طباعة الصفحة الحالية والتقارير والكشوف والمحتوى الذي يتم توليده في نافذة طباعة خاصة.
- عند تشغيل `index.html` في متصفح عادي يبقى هناك بديل للطباعة عبر `window.print()`.
- لا توجد أي حاجة للإنترنت أثناء إنشاء وطباعة البيانات المحاسبية بعد تثبيت التطبيق.

## بناء APK
استخدم ملف GitHub Actions الموجود في:
`.github/workflows/build-apk.yml`

الناتج سيكون Artifact باسم:
`pro-accounting-stage7-apk`
