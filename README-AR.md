# أسامة سوفت — المرحلة 11: أساس قاعدة البيانات المنظمة

هذه النسخة تحتوي على **الملف الأصلي العامل كما هو** بالإضافة إلى أساس SQLite منظم.

## مهم
- `www/index.html` هو الملف الأصلي بحجم 553,859 بايت ولم تتم إعادة كتابة وظائفه.
- قاعدة البيانات الجديدة اسمها `osama_soft_accounting`.
- المخطط موجود في `www/database/schema.sql`.
- خدمة SQLite موجودة في `www/database/db-service.js`.
- شاشة فحص القاعدة موجودة في `www/tools/database-inspector.html`.
- لا توجد أي بيانات محاسبية تجريبية في `seed.sql`؛ الموجود فقط بيانات مرجعية للصلاحيات.

## ما تم تصميمه
- الشركات والفروع.
- المستخدمون وربط المستخدم بالشركات والفروع.
- مجموعات الصلاحيات والصلاحيات التفصيلية.
- العملات وأسعار الصرف التاريخية.
- دليل حسابات موحد على مستوى الشركة بدون إنشاء حساب لكل عملة.
- الحسابات التحليلية والعملات المسموحة لها.
- العملاء والموردون والصناديق والبنوك وشركات الصرافة.
- الحسابات الوسيطة بين الفروع.
- الفترات المالية والإقفالات والأقفال الزمني.
- القيود اليومية وسطور القيود متعددة العملات والأسعار والبيان لكل سطر.
- سندات القبض والصرف وتفاصيلها.
- الإيرادات والمصروفات.
- الأرصدة الافتتاحية.
- الموازنات وسطور الموازنات.
- إعادة تقييم فروق العملة وسطورها.
- الاستبعادات من إعادة التقييم.
- إعدادات النظام والتسلسلات.
- سجل الرقابة Audit Log.

## ما لم يتم فعله عمدًا
لم يتم ربط `index.html` الحالي بقاعدة البيانات الجديدة بعد. هذا مقصود حتى لا نخاطر بالنسخة العاملة قبل اختبار طبقة قاعدة البيانات مستقلة.

الخطوة التالية هي ربط **وحدة واحدة فقط في كل مرة** بقاعدة البيانات الجديدة، بدءًا من الشركات/الفروع ثم العملات ثم الدليل ثم الحسابات التحليلية ثم العمليات، مع اختبار APK بعد كل مرحلة.
