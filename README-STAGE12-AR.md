# أسامة سوفت — المرحلة 12: ربط قاعدة البيانات المنظمة

## الحالة
النسخة الحالية من `www/index.html` هي الملف الأصلي العامل نفسه، حجمه 553,859 بايت قبل إضافة ملفات الربط، ولم تتم إعادة كتابة وظائف المحاسبة داخله.

## ما أصبح فعلياً
- SQLite منفصل باسم `osama_soft_accounting` على Android عند توفر Capacitor SQLite.
- مخطط منظم متعدد الجداول.
- `schema_migrations` لتتبع إصدار المخطط.
- بيانات مرجعية للصلاحيات فقط، بدون بيانات محاسبية تجريبية.
- طبقة `www/database/db-service.js` مسؤولة عن الاتصال وتنفيذ SQL والقراءة والتصدير.
- واجهة `www/database/database-ui.js` داخل الإعدادات لعرض الجداول والصفوف.
- مستودع مستقل `www/database/repositories/organization-repository.js` للشركات والفروع والمستخدمين والصلاحيات.

## مبدأ التطوير
لن نعيد كتابة `index.html` عند تطوير وحدة جديدة. كل وحدة جديدة ستتصل بطبقة قاعدة البيانات عبر Repository/Service مستقل، وتضاف تغييرات قاعدة البيانات عبر migration مستقل.

## ملاحظة البيانات
لا توجد عملية ترحيل للبيانات القديمة ولا حذف تلقائي لها. قاعدة `osama_soft_accounting` مستقلة عن قاعدة `pro_accounting` القديمة الموجودة في النسخة الحالية.
